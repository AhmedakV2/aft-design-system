# Keyboard contract

| Eylem | macOS | Windows/Linux |
|---|---|---|
| Komut paleti | Cmd+K | Ctrl+K |
| Senaryo aç | Cmd+P | Ctrl+P |
| Kayıt başlat/bitir | Cmd+Shift+R | Ctrl+Shift+R |
| Senaryoyu çalıştır | Cmd+R | Ctrl+R |
| Debug çalıştır | F5 | F5 |
| Adım adım | F10 | F10 |
| Durdur | Shift+F5 | Shift+F5 |
| Breakpoint | F9 | F9 |
| Ajan paneli | Cmd+I | Ctrl+I |
| Seçimi Ajan'a gönder | Cmd+L | Ctrl+L |
| Liste paneli | Cmd+B | Ctrl+B |
| Terminal | Cmd+J | Ctrl+J |
| Modüller | Cmd+1…6 | Ctrl+1…6 |
| Bölgeler arası | F6 | F6 |
| Ayarlar | Cmd+, | Ctrl+, |

Geçiş döneminde eski Ctrl+P command palette davranışı iki sürüm uyumluluk ipucuyla desteklenebilir.
