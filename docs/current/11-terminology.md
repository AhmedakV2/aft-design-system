# Terminology

| Terim | Anlam |
|---|---|
| Senaryo | Bir iş akışını test eden adımlar bütünü |
| Adım | Tek eylem: git, yaz, tıkla, seç, bekle, doğrula… |
| Koşum | Bir senaryonun tek çalıştırılması ve sonucu |
| Kimlik | Bir adımın hedeflediği element tanımı; UI'da “descriptor” yazılmaz |
| Kimlik kalitesi | Kimliğin doğru elementi tek başına bulma güveni |
| Kararsız | Aynı koşullarda bazen geçen bazen kalan senaryo/adım |
| Geçti | Başarıyla tamamlanan koşum/adım |
| Kaldı | Assertion veya beklenen davranış karşılanmadı |
| Hata | Sistem/altyapı/çalıştırma hatası |
| İptal | Kullanıcı veya sistem tarafından tamamlanmadan durduruldu |

Kural: aynı kavrama iki kelime, iki farklı kavrama aynı kelime verilmez.
