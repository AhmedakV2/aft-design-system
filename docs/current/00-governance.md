# Governance

## Source of truth
ADR → token → current docs → UI code → source-spec → references.

## Değişiklik türleri
- **Token değişikliği:** visual regression + contrast kontrolü zorunlu.
- **Primitive component:** Storybook, keyboard, a11y ve state matrisi zorunlu.
- **Pattern değişikliği:** en az bir module contract güncellenir.
- **IA değişikliği:** ADR zorunlu.
- **Marka değişikliği:** ADR + token + logo asset güncellemesi birlikte yapılır.

## Definition of Ready
Bir tasarım işi başlamadan önce kullanıcı görevi, primary action, state'ler ve veri bağımlılıkları bilinmelidir.
