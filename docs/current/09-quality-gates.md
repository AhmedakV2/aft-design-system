# Quality gates

## Otomatik
- token contrast check
- raw-hex / cursor-pointer design-rule scan
- TypeScript typecheck
- Storybook build
- axe accessibility
- visual regression

## Performans hedefleri
- cold start < 2 s
- white flash yok
- direct interaction feedback < 100 ms
- spinner 300 ms'den önce görünmez

## Visual QA
- 4 px grid
- %125 Windows sharpness
- nested radius
- tabular numbers
- Turkish locale casing
- light/dark/system
- keyboard-only task completion
- empty/loading/error/success

## Test yaklaşımı
“Ara yüzü beğendiniz mi?” yerine görev tamamlama süresi, hata sayısı ve beklenen davranış sorulur. Gerekirse grayscale prototip turu yapılır.
