# UX writing

- Button copy fiille başlar.
- “Tamam / Evet / Hayır” yerine sonucu açıklayan action kullan.
- Internal terms yalnız Tanılama'da.
- Error = Ne oldu + biliniyorsa neden + kullanıcı ne yapabilir.
- TR/EN layout copy'nin %30 uzamasını kaldırmalı.
- Empty state yalnız gerçekten veri yoksa; tek cümle + tek action.
- “Seçim yapılmadı” gibi teknik state'i kullanıcıya gereksiz yere gösterme; mümkünse son kullanılan öğeyi aç.
