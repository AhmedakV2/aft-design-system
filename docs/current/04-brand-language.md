# Brand language

## AFT Orange
Primitive palet `packages/tokens/src/primitives.json` içindedir.

- Orange = action / execution / active selection
- Green = success
- Amber = warning / unstable / weak
- Red = failure / destructive
- Record Red = recording mode
- Blue = informational / links
- Violet = Agent / AI

## Orange kullanım sınırı
- Primary CTA
- aktif navigation işareti
- aktif tab underline
- focus/selection accent
- marka işareti
- ana chart series gerektiğinde

Orange dekoratif arka plan, büyük gradient veya her icon için kullanılmaz.

## Logo
Mevcut “A” işareti korunur ve sadeleştirilir. Ana marka rengi Orange. Dark zeminde gerektiğinde açık/white varyant. Gölge ve gradient yok.

## Ürün dili
Butonlar fiille başlar: “Senaryoyu çalıştır”, “Zayıfları onar”. “Tamam / Evet” yerine sonucu söyleyen action kullanılır. Hata copy'si: **Ne oldu + neden + ne yapılabilir**.
