# 23. Klavye Kısayolları

> Arşiv kaynak: `source/AFT_Tasarim_Sistemi_v1.docx`. Bu dosya tarihsel v1 spesifikasyonudur. Güncel kararlar için `docs/current/` ve `docs/decisions/` önceliklidir.

| Eylem | macOS | Windows / Linux |
| --- | --- | --- |
| Komut paleti | ⌘K | Ctrl+K |
| Senaryo aç | ⌘P | Ctrl+P |
| Kaydı başlat / bitir | ⌘⇧R | Ctrl+Shift+R |
| Senaryoyu çalıştır | ⌘R | Ctrl+R |
| Hata ayıklayarak çalıştır | F5 | F5 |
| Adım adım | F10 | F10 |
| Durdur | ⇧F5 | Shift+F5 |
| Breakpoint | F9 | F9 |
| Ajan paneli | ⌘I | Ctrl+I |
| Seçimi Ajan’a gönder | ⌘L | Ctrl+L |
| Liste paneli | ⌘B | Ctrl+B |
| Terminal | ⌘J | Ctrl+J |
| Modüller 1–6 | ⌘1 … ⌘6 | Ctrl+1 … Ctrl+6 |
| Bölgeler arası | F6 | F6 |
| Ayarlar | ⌘, | Ctrl+, |
| Geri al / Yinele | ⌘Z / ⌘⇧Z | Ctrl+Z / Ctrl+Y |

```text
Geçiş notu:  Mevcut sürümde komut paleti Ctrl+P. Yeni standart Ctrl+K (palet) ve Ctrl+P (senaryo aç). Kullanıcı alışkanlığını kırmamak için iki sürüm boyunca Ctrl+P paleti de açar ve ilk kullanımda tek seferlik bir ipucu gösterilir.
```
